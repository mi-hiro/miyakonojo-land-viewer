# 都城市 売土地ビューア

Androidスマホで見るための試作版です。

## 開き方

`index.html` をブラウザで開きます。

アプリは最初にGitHub上の `latest.json` と `history.json` を読みに行きます。
取得できない場合は、このフォルダに同梱している `latest.json` と `history.json` を表示します。

## 表示内容

- 物件一覧
- 一覧のカード・コンパクト・表形式切替
- 物件写真
- ワード検索
- 価格と面積の範囲絞り込み
- 学校区での絞り込み
- 金額順、面積順、坪単価順、新着順の並び替え
- 新着、割安新着の絞り込み
- お気に入り、買付候補、除外リスト
- 物件ごとのメモ
- お気に入り、買付候補、除外、メモのバックアップ保存・復元
- 値下げ検知
- 物件詳細
- 地図表示
- 通常地図と航空写真の切替
- 物件詳細内のミニ地図
- 掲載文に地番がある場合の地番表示
- 町名別の現在平均と履歴平均
- 坪単価の分布グラフ
- 買付候補の比較表
- 物件ごとの割安査定根拠
- 固定資産税路線価を使った参考査定
- 接道幅員4m未満の要セットバック候補表示
- 接道状況から接道方角・道路幅員・接面を表示
- 告知事項あり物件の注意表示
- ハザードマップ調査結果の表示
- 小学校・中学校の学校区と徒歩距離の概算

## 地図

緯度経度がある物件はその位置に表示します。
緯度経度がない物件は、町名ごとの概算位置に表示します。
物件詳細にも同じ位置情報を使ったミニ地図を表示します。
地図右上の切替で、通常地図と航空写真を切り替えできます。

## 写真

レポート生成側で `image_url` が取得できた物件は写真を表示します。
まだ写真URLがない物件は、町名、価格、坪単価を入れた地図風の代替ビジュアルを表示します。
複数の写真URLがある物件は、詳細画面でサムネイル表示します。
1枚目が表示できない場合は、次の写真URLを自動で試します。
今後の収集では一覧ページに加えて物件詳細ページの画像URLも確認します。
外部表示が制限されている画像は、URLを取れてもアプリ内に表示できない場合があります。

## 割安査定

同じ町の現在掲載平均との差、履歴平均、全体平均を使って概算の比較基準を作ります。
`route-values.json` に路線価が登録されている物件は、路線価を公示価格水準に換算した参考坪単価も比較基準に加えます。
物件詳細では、比較基準、平均との差、割安率、概算査定額、根拠を表示します。
国税庁路線価方式の参考査定は、相続税路線価、接面、概算奥行、セットバック候補、不整形などを使って表示します。
接道、形状、高低差、上下水、建築条件などは十分に取れていないため、購入判断用の正式査定や税務申告用評価ではありません。

## 検討管理

一覧または詳細で、お気に入り、買付候補、除外を切り替えできます。
買付候補に入れた物件は「比較」タブで価格、面積、坪単価、査定、学校区、注意点、メモを横並びで確認できます。
除外した物件は通常の一覧から非表示になり、「除外表示」をオンにすると再表示できます。
メモはブラウザ内に保存されます。

## バックアップ

「バックアップ保存」で、お気に入り、買付候補、除外、メモをJSONファイルに書き出します。
保存先にOneDriveやGoogle Driveを選ぶか、保存後にクラウドフォルダへ移動します。
「復元」でJSONファイルを読み込むと、現在の保存データに合流します。
端末変更やブラウザのキャッシュ削除に備えて、定期的な保存をおすすめします。

## 国税庁路線価方式・路線価

不動産情報ライブラリAPIキーを設定すると、鑑定評価書情報APIから相続税路線価を取得し、`route-values.json` に近接標準地ベースの候補を保存します。
`route-values.json` の `items` に手入力する場合も、路線価は円/㎡で登録します。
物件ID、掲載URL、所在地、緯度経度、町名の順に照合し、照合精度も表示します。
相続税路線価は、国税庁の路線価方式に合わせて `正面路線価 × 補正率 × 地積` を基本に参考査定します。
接面と道路幅員が分かる場合は、4m未満道路のセットバック候補について、セットバック部分の70%控除を概算表示します。
間口狭小、奥行長大、不整形地は、掲載情報から分かる範囲の簡易係数、または `frontage_correction_rate` などの手入力補正率を使います。
固定資産税路線価を手入力した場合は、従来通り公示価格水準の参考坪単価へ換算して表示します。

## 接道・告知

掲載文、制限情報、備考、接道状況から接道方角、道路幅員、接面、セットバック、再建築、43条但書、告知事項の表現を検出します。
接道幅員が4m未満と読める物件は「要SB」バッジを表示し、物件詳細に「要セットバック候補」と表示します。
「告知事項有」「心理的瑕疵」などの表現がある物件は「告知」バッジを表示します。
掲載文ベースの自動検出なので、重要事項説明や役所確認の代替にはなりません。

## ハザード

`hazard-zones.json` の `items` に、都城市WEB版防災マップや国土交通省ハザードマップポータルで確認した調査結果を登録します。
洪水浸水想定区域、土砂災害警戒区域、内水、ため池などの種類とレベルを登録できます。
物件ID、掲載URL、所在地、緯度経度、町名の順に照合し、該当ありの場合は「ハザード」バッジと物件詳細に表示します。
未登録の物件は「未調査」と表示します。

## 学校区

都城市公式の小学校・中学校通学区域をもとに、町名ベースで表示します。
一部地域で学校区が分かれる町は「要確認」と表示します。
徒歩距離は町名の概算位置または物件位置から学校までの直線距離を歩行距離に補正した概算です。

## スマホで使う場合

このフォルダをWebで公開すると、AndroidのChromeから開いてホーム画面に追加できます。
APK化する場合も、この画面をそのままAndroidのWebViewに入れられます。
